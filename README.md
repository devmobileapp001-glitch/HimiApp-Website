# NOVA Studio website

Website tĩnh đa trang dành cho một studio phát triển ứng dụng Android/AI.

## Xem website

Mở `dist/index.html` trực tiếp trong trình duyệt, hoặc chạy một static web server từ thư mục `dist`.

## Cấu trúc trang

- `index.html` — Landing page
- `apps.html` — Danh mục ứng dụng
- `about.html` — Giới thiệu studio
- `contact.html` — Liên hệ
- `support.html` — Hỗ trợ và FAQ
- `privacy.html` — Privacy Policy cho app
- `terms.html` — Terms of Use
- `404.html` — Trang không tìm thấy

## Trước khi phát hành thật

Thay tên studio, địa chỉ email, thông tin liên hệ, liên kết Google Play và rà soát nội dung pháp lý theo dữ liệu/thư viện thực tế của từng ứng dụng.
